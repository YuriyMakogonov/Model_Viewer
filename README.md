# Model Viewer

Просмотр 3D-моделей OBJ и STL и примерный расчёт пластика для FDM-печати. Сделано на Godot 4.7, код на GDScript.

## Запуск
Откройте `project.godot` в Godot и нажмите F5. Или из терминала:

```bash
/Applications/Godot_mono.app/Contents/MacOS/Godot --path . -- путь/к/модели.stl
```

## Что умеет
- Открывает OBJ (с `usemtl` и цветами из `.mtl`) и STL (бинарный и текстовый): через кнопку или перетаскиванием в окно.
- Вращение, сдвиг и масштаб мышью или трекпадом. Режим каркаса, стол принтера.
- Показывает габариты, объём, площадь, число треугольников и вершин, проверяет, замкнута ли сетка, выводит список материалов из файла.
- Считает массу, длину нити и стоимость по пластику, заполнению, толщине оболочки и запасу на поддержки.
- Проверяет, помещается ли модель на стол.

## Структура
- `scripts/mesh_loader.gd` — разбор OBJ/STL.
- `scripts/mesh_analyzer.gd` — объём, площадь, замкнутость, массивы для отрисовки.
- `scripts/print_estimate.gd` — формула расхода пластика.
- `scripts/orbit_camera.gd` — камера.
- `scripts/main.gd` — окно и интерфейс.
- `tests/run_tests.gd` — тесты расчётов.
